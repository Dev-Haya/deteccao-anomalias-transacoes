# deteccao-anomalias-transacoes
Projeto de detecção de fraudes em transações. Evitei data leakage separando os dados antes do StandardScaler e SMOTE. Comparei Regressão Logística, Random Forest e XGBoost (com ajuste de limiar para otimizar o Recall). Finalizei com GridSearchCV e SHAP para explicabilidade do modelo.
